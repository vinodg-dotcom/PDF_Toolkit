# PDF Toolkit – Offline PDF Management Application

A desktop-based PDF management application developed using Python and CustomTkinter. The application provides multiple PDF operations through a user-friendly graphical interface and works offline.

## Features

- Add and manage multiple PDF files
- Merge PDF documents
- Split PDF documents
- Reorder PDF files
- Rotate individual PDF pages with live preview
- Delete PDF pages with preview
- Extract selected PDF pages
- Rearrange individual pages with preview
- Add text watermarks
- Add page numbers
- Compress PDF files
- Password-protect PDF files
- Unlock PDFs using the existing password
- Convert PDF pages into PNG images
- Convert images into PDF documents

## Technologies Used

- Python
- CustomTkinter
- PyMuPDF
- pypdf
- Pillow

## Installation

Install the required dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python main.py
```

## Key Highlights

- Offline PDF processing
- Graphical user interface
- Live page preview for page-level operations
- Original PDF files are preserved when saving modified documents
